# Custom Accessory GLB Models

Optional custom 3D model parts can be placed here to extend the default procedural accessories:
- `public/models/parts/glasses/<id>.glb`
- `public/models/parts/hat/<id>.glb`
- `public/models/parts/audio/<id>.glb`

By default, BitVRM ships with built-in procedural Three.js accessories in `lib/accessories.ts` (`smart_glasses`, `cap`, `headphones`) that require zero external model files and run with zero download latency.
